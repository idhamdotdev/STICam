### Why the source code is private

The Developer is an independent solo developer. STICam's source code, architecture,
and implementation are among his primary professional assets. Keeping them private
protects the ability to license custom versions, offer commercial support, and build a
sustainable practice under the idham.dev brand.

The source is private for intellectual-property reasons — **not** to conceal unlawful
use of anyone else's code. Every third-party component STICam uses is disclosed in
[THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md), with checksums where the component is
a binary. The project welcomes verification and, where a legitimate need exists, an
independent code or security audit can be arranged under a non-disclosure agreement.
